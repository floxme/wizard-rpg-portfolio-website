## ZIP und Git

1. Archiv außerhalb des bestehenden Repositorys entpacken.
2. Inhalt des Ordners `the-arcane-tower` in das Projektverzeichnis übernehmen: AGENTS.md und README.md liegen direkt an der Repository-Wurzel, daneben docs/ und prompts/.
3. Vorhandene gleichnamige Dateien vergleichen und zusammenführen; niemals ungeprüft ersetzen.
4. In VS Code die Änderungen prüfen. Florian erstellt Commit und Push selbst.
5. Die ZIP außerhalb des Repositorys behalten. Einzelne Markdown-Dateien werden versioniert, damit Unterschiede lesbar sind.

Das Paket enthält bewusst keine Kopien der großen Modelle oder vollständiger Chats. Die bestehenden Asset-Archive bleiben erhalten; `docs/context/assets.md` ordnet ihre Inhalte zu. Finale Referenzen später nach dokumentierten Zielpfaden übernehmen. Rohchats nicht in ein später öffentliches Repository aufnehmen.

## Vorgehen

Zuerst ein vollständig bedienbarer Prototyp mit Platzhaltern. Danach visuelle Ausarbeitung, Magier- und Umgebungsassets, Animationen und Audio. Veröffentlichung erst nach Inhalts-, Rechte- und Funktionsprüfung. Quellcode bleibt zunächst privat; UI zeigt „Quellcode derzeit privat“.

Spätere Änderungen dieser Dokumentation brauchen vorherige ausdrückliche Zustimmung gemäß AGENTS.md.
